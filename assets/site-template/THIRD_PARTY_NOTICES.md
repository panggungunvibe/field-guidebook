# 素材与来源

## 网站设计参考

交互与视觉结构参考 [Deimos — evilrabbit](https://deimos.evilrabbit.com/)。本项目交付可读的本地实现，不附带原站的打包 JavaScript、原站图片或原站文章。保留此来源说明；本项目并非 Deimos 的官方发行。

## 字体

`public/fonts/geist-latin.woff2` 与 `geist-serif.ttf` 来自 [Geist](https://github.com/vercel/geist-font)。Geist Serif 内嵌版权为 Copyright 2026 The Geist Project Authors。字体使用 SIL Open Font License 1.1，许可原文随字体置于 `public/fonts/OFL.txt`。字体不受本项目 MIT 许可覆盖。

## FRIM 示例

默认演示包含 Forest Research Institute Malaysia（FRIM）的名称与官网公开 Logo，来源为 [FRIM 官网](https://www.frim.gov.my/)。这些标识归原机构所有，不因本仓库的 MIT 许可转让或获得官方背书。换成自己的主题时同步替换机构标识。

`public/plants/` 的现场照片由项目作者提供，保留作者权利，不纳入代码的 MIT 许可。它们随模板用于恢复示例效果；制作和发布自己的主题时请替换成自己的照片或有相应授权的素材。演示录制与截图同样包含这些示例素材。

示例文字保留条目级的公开参考链接。原始私人云文档链接不随仓库分发；`public/field-notes.html` 仅是随包照片的图注索引，不是原始文档或新的植物鉴定证据。

## npm 依赖

Vite 及其依赖保持各自的许可证，版本锁定于模板的 `package-lock.json`。本仓库不包含 `node_modules`；首次运行通过 npm 安装。
